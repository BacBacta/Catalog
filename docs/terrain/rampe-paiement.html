Minimum Orange Money Orange refuse les montants sous 10 FCFA (erreur ER201, relevée sur l'API le 29/07/2026), là où MTN accepte 5. À contrôler côté formulaire, pas seulement côté serveur.
Ce que Catalog ne voit jamais Votre code secret ne se tape pas ici. Il se saisit dans la session de l'opérateur, après l'appel — Catalog est hors circuit dès que vous appuyez sur composer. L'argent va de votre portefeuille au sien, directement.
Comment ça se passe
  1. Vous touchez Composer — le clavier de votre téléphone s'ouvre, déjà rempli : bon numéro, bon montant.
  2. Vous appuyez sur appeler. La session MTN ou Orange prend le relais.
  3. Vous confirmez et saisissez votre code secret chez l'opérateur.
  4. La vendeuse reçoit le SMS de l'opérateur et le colle dans Catalog. Le reçu apparaît, avec l'identifiant de transaction.
Le point à établir sur le terrain Les codes d'entrée sont désormais confirmés : *126# chez MTN et #150*50# chez Orange — relevés le 29/07/2026 dans la réponse de l'API CamPay, qui les renvoie par transaction. Leçon d'implémentation : le code doit venir de la réponse de l'opérateur, jamais d'une constante en dur.
