# Runbooks

Un fichier par incident, avec toujours la même structure : symptômes,
diagnostic, actions, critère de sortie.

À rédiger en phase 5 :

- `panne-operateur.md` — MTN ou Orange indisponible, paiements suspendus
- `ecart-reconciliation.md` — le grand livre diverge du relevé de l'agrégateur
- `paiement-conteste.md` — l'acheteuse affirme avoir été débitée sans confirmation
- `restauration-sauvegarde.md` — procédure testée, avec le temps réellement mis
